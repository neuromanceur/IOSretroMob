# Evidence-driven roadmap

1. **Publication baseline:** one attributed engine, firmware-free build/tests, exact authentic captures and audited Git history. No publication until owner approval.
2. **Completed native game baseline:** preserve Relic Maze ARMv6 guest victory, tactile callbacks and independent per-layer captures. Consolidated local sources do not imply remote publication, Unity execution or sustained FPS.
3. **Full display:** establish S5L8900 layer priority, alpha coefficients, rounding and color processing before calling the experimental CLCD composition hardware-faithful. Reuse the existing layers before authorizing any new guest campaign.
4. **Depth:** identify measured external-Z storage format and test/write/clear state; create independent known-geometry references; prove guest occlusion and atomic rejection of unsupported modes. Observation of addresses alone is insufficient.
5. **Program/state coverage:** add only complete measured families with bounds, negative tests and independent pixel evidence. Resolve dither and blend separately. No blanket OpenGL ES claim.
6. **Snapshot format boundary:** assign a distinct lineage-aware format for future states and explicitly test migration from our local v32/v33; never silently load current upstream v33.
7. **Historical Unity:** secure authorization for a legally usable runtime; resolve real imports/ABI; demonstrate startup, frame production and controlled input in the guest before claiming game compatibility. Temple Trouble remains unvalidated.
8. **Android ARM64 host:** reproduce cross-compilation, add a minimal JNI/host front end, and measure boot, rendering, audio, touch, memory and temperature on a physical S23. The nine compiled targets are only the starting compile evidence.
9. **Preservation records:** maintain application-specific source revision, firmware identity, configuration, input, artifacts and explicit unsupported behavior. Publish only redistributable own inputs.

No dates or sustained performance promises are assigned before these acceptance gates pass.
