# Level solution (spoiler)

The level has a shortest known path of **25 steps**, found by an independent breadth-first solver and exercised against both the C and JavaScript engines:

`DDDDDDUURRRUURUUDDRRDDDDL`

`U` = up, `D` = down, `L` = left, `R` = right.

Goal: collect all three relics, place the crate on the pressure plate and reach the exit. The gate is open only while the crate stays on the plate.
